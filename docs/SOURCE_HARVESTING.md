# Source Harvesting And Historical Evidence

External directories are discovery inputs, not permanent dependencies. A listing may change, disappear, merge with another listing, or be removed after an acquisition.

## Required Source Record

Every imported external listing should retain:

- Publisher and source URL
- Access timestamp
- Page title
- Visible listing name and operator
- Published address or approximate location
- Published lifecycle status
- Published capacity and technical facts
- Original description text
- Linked images or documents when reuse is permitted
- Snapshot location or archival reference
- Content hash for later change detection
- Review notes and disposition

## Preservation Rules

- Store factual extracts and citations in the project inventory.
- Preserve the original external URL even when the page later disappears.
- Do not copy copyrighted page layouts or bulk proprietary datasets.
- Use public pages for manual research unless the publisher permits automated harvesting.
- Capture the access date every time a source is reviewed.
- Mark stale, removed, or changed records instead of deleting them.
- Keep old claims attached to the version of the facility record where they were used.

## Source Hierarchy

1. Government, county, permit, utility, and property records
2. Operator or developer sources
3. Data Center Map and Baxtel
4. Reputable local reporting
5. Community reports and discovery-only sources

The inventory can publish a record from a directory when the directory provides a concrete physical site, but the confidence and source role must say that the directory is the basis. A primary source should be sought before publishing detailed impact claims.
