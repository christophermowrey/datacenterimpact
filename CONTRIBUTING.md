# Contributing

Contributions are welcome, but accepted contributions become the property of Christopher Mowrey.

Before a pull request is merged, the contributor must agree to the contributor assignment terms in `CLA.md`. The assignment gives Christopher Mowrey the right to use, modify, relicense, sublicense, and commercialize the contribution as part of Data Center Impact.

Do not submit confidential information, credentials, copyrighted material without permission, or copied directory data that cannot be redistributed.

Run these checks before submitting:

```bash
npm test
npm run build
```
